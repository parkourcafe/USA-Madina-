## Как доложить постеры в репо (2 минуты, любой из путей)

1. **Через GitHub-интерфейс:** открой ссылки в браузере → сохрани картинки →
   в этой папке GitHub → «Add file → Upload files». Можно грузить как есть
   (PNG, любые имена) — следующая Claude-сессия сама переименует, сконвертирует
   в JPG (~q80, ≤ 300 KB) и почистит. Либо сразу переименуй по левой колонке
   (расширение тогда поменяй на `.jpg` — сайт ждёт именно эти имена).
2. **Через Claude-сессию с открытой сетью:** разреши в network policy
   окружения хост `d8j0ntlcm91z4.cloudfront.net` — и попроси сессию докачать
   по ссылкам выше (job ID приложены для контроля).
